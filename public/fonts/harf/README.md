# Harf wordmark typography

Fonts are self-hosted so the product identity does not depend on an external font service. The font files are unmodified and their SIL Open Font License notices are included beside them.

- Manrope variable: English wordmark, weight 800. Source: https://github.com/google/fonts/tree/main/ofl/manrope
- Lalezar Regular: Arabic wordmark, weight 400. Source: https://github.com/google/fonts/tree/main/ofl/lalezar
- Noto Naskh Arabic variable: retained alternative font asset. Source: https://github.com/google/fonts/tree/main/ofl/notonaskharabic
- Noto Kufi Arabic variable: retained alternative font asset. Source: https://github.com/google/fonts/tree/main/ofl/notokufiarabic
- Aref Ruqaa Bold: retained previous Arabic font asset. Source: https://github.com/google/fonts/tree/main/ofl/arefruqaa

Use `Harf حرف`, without a slash, on primary product headers. Use `Harf` for compact wordmarks and technical product labels. These font families are reserved for branding in the interface; normal application text retains its existing fonts.
